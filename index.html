Mes réservations

📭 Vous n'avez pas encore de réservation. Cliquez sur « Réserver » dans le menu pour commencer.

    Aide

    Comment réserver ?

    Choisissez une date, les heures et une salle, puis cliquez sur « Réserver ».

    J'ai un message rouge, que faire ?

    Le message vous dit quel champ remplir ou corriger.

    Comment annuler ?

    Dans « Mes réservations », cliquez sur « Annuler ».
